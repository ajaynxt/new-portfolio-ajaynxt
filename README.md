# AJAY NXT Portfolio

Upload all files and folders to the web root of ajaynxt.com.

Important files:
- index.html: main portfolio
- projects.html: full archive
- styles.css / script.js: design and interactions
- robots.txt / sitemap.xml: search engine discovery
- 404.html: custom error page
- manifest.webmanifest: install metadata

After deployment, submit https://ajaynxt.com/sitemap.xml in Google Search Console.
