# AJAY NXT Premium Portfolio

A responsive two-page portfolio website for Ajay Saini / AJAY NXT.

## Pages

- `index.html` - Main portfolio
- `projects.html` - 25+ project archive and filters

## Included

- Approved AJAY NXT hero portrait
- Premium responsive desktop and mobile layout
- Continuous light color-flow background
- Pause / resume color-flow control
- Infinite services marquee
- 4-project featured slider
- Project screenshots with full-screen lightbox
- 25+ projects archive
- Responsive films and reels slider
- Video modal prepared for vertical and horizontal videos
- Services, About, worldwide currency section
- Project inquiry form that opens a structured WhatsApp message
- Floating WhatsApp contact button
- Reduced-motion and keyboard accessibility support

## Add videos

Place your MP4 files in `assets/videos/` using these names:

- `reel-01.mp4`
- `film-01.mp4`
- `reel-02.mp4`
- `promo-01.mp4`
- `reel-03.mp4`

Full instructions are in `assets/videos/ADD-YOUR-VIDEOS-HERE.txt`.

## Run locally

Open `index.html` directly, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Upload the full folder to Netlify, Vercel static hosting, Firebase Hosting, GitHub Pages, or any standard web hosting account.
